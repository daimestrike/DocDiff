# DocDiff — сравнение документов

Веб-сервис для внутреннего контура: загружаете две версии документа — сразу видите, что изменилось.

- **Word** (`.docx`) — абзацы, заголовки, таблицы; изменения подсвечиваются до слова.
- **Excel** (`.xlsx`, `.xlsm`, `.xls`) и **CSV** — сравнение по листам и строкам: добавленные/удалённые строки, изменённые ячейки (`C3: 79 → 84`), добавленные/удалённые листы.
- **PDF**, **PowerPoint** (`.pptx`), текстовые файлы (`.txt .md .json .xml .yaml .sql …`, UTF-8 и Windows-1251).
- `.doc .rtf .odt .ods .ppt` — если на сервере есть LibreOffice (см. [ниже](#старые-форматы-doc-rtf-odt)).
- Разные форматы между собой (например, `.docx` ↔ `.pdf`) — сравниваются как текст.

Что умеет интерфейс: drag & drop, сравнение запускается сразу после выбора второго файла,
режим «только различия» со сворачиванием одинаковых фрагментов, навигация по изменениям
(`n` / `p`), опции «не учитывать регистр / пробелы», выгрузка **самодостаточного HTML-отчёта**
(открывается в любом браузере без сервера — удобно отправить коллеге).

Ничего не хранится и не уходит наружу: временные данные удаляются сразу после сравнения,
интерфейс не грузит внешних шрифтов/скриптов/CDN.

## ⚡ Запуск на сервере без интернета за 1 минуту

1. На любой машине с интернетом скачайте готовый архив со страницы
   **[Releases](https://github.com/daimestrike/DocDiff/releases/latest)**:

   | Сервер | Архив |
   |---|---|
   | Linux x86_64, без Docker — **самый простой вариант** | `docdiff-X.Y.Z-linux-x86_64.tar.gz` |
   | Linux ARM (aarch64), без Docker | `docdiff-X.Y.Z-linux-aarch64.tar.gz` |
   | На сервере есть Docker | `docdiff-X.Y.Z-docker-amd64.tar.gz` |

   Python и все зависимости уже внутри архива: на сервере ничего не скачивается и не
   компилируется, системный Python не нужен.

2. Перенесите архив на сервер (scp, флешка, файлообменник) и выполните:

   ```bash
   tar xzf docdiff-*.tar.gz && cd docdiff && sudo ./install.sh
   ```

   `install.sh` сам поставит systemd-сервис (или поднимет Docker-контейнер) с автозапуском.
   Без root: `./start.sh` — и сервис доступен на `http://<сервер>:8080`.

Архивы собирает GitHub Actions при каждом теге `v*` (см. [выпуск новой версии](#выпуск-новой-версии)).

## 1. Быстрый старт локально

Нужен Python 3.9+.

```bash
./run.sh
```

Откройте <http://localhost:8080>. Скрипт сам создаст `.venv` и поставит зависимости.

Демо-файлы (договор в Word и прайс в Excel, две версии каждого):

```bash
make examples     # создаст examples/contract_v1.docx, contract_v2.docx, price_v1.xlsx, price_v2.xlsx
make demo         # сравнит их в терминале и сохранит examples/report.html
make test         # тесты
```

Все команды: `make help`.

## 2. Деплой на сервер без интернета

Схема общая для всех вариантов:

```
[машина с интернетом]                        [сервер в контуре]
Releases на GitHub  ─┐
  или make bundle-*  ─┴─ docdiff-*.tar.gz ──►  tar xzf … && cd docdiff && sudo ./install.sh
                                               → http://<сервер>:8080
```

`install.sh` сам понимает тип архива и ничего не качает из сети.

### Вариант A: портативный (рекомендуется)

Внутри архива — готовый Python 3.11 ([python-build-standalone](https://github.com/astral-sh/python-build-standalone))
и все библиотеки. Требования к серверу: только Linux x86_64 или aarch64 с glibc ≥ 2.17
(CentOS 7+, RHEL 7+, Astra, РЕД ОС, Debian, Ubuntu…). Размер ~45 МБ.

```bash
tar xzf docdiff-1.0.0-linux-x86_64.tar.gz && cd docdiff
sudo ./install.sh     # systemd-сервис docdiff с автозапуском
# или без root:
./start.sh            # запуск в текущем терминале
./docdiff-cli old.docx new.docx --html report.html   # сравнение из командной строки
```

Собрать архив самому (на Mac или Linux с интернетом):

```bash
make bundle-portable                 # → dist/docdiff-1.0.0-linux-x86_64.tar.gz
ARCH=aarch64 make bundle-portable    # для ARM-сервера
```

### Вариант B: Docker

Требования к серверу: Docker + `docker compose` (или `docker-compose`).

```bash
tar xzf docdiff-1.0.0-docker-amd64.tar.gz && cd docdiff
sudo ./install.sh     # docker load + docker compose up -d
```

Собрать самому (нужен Docker): `make bundle-docker`. Для ARM: `PLATFORM=linux/arm64 make bundle-docker`.
С поддержкой `.doc/.rtf/.odt`: `WITH_LIBREOFFICE=1 make bundle-docker`.

### Вариант C: под системный Python сервера

Если по политике безопасности нельзя приносить свой интерпретатор — пакет с колёсами под
Python, уже установленный на сервере (3.9+):

```bash
python3 --version                       # на сервере, например 3.11
PY_VERSION=3.11 make bundle-venv        # на машине с интернетом
# на сервере:
tar xzf docdiff-1.0.0-venv-py3.11-x86_64.tar.gz && cd docdiff && sudo ./install.sh
```

Скрипт создаст `.venv`, поставит зависимости из `wheels/` (`pip --no-index`), при отсутствии
пакета `python3-venv` поставит pip из колеса. Другой интерпретатор: `sudo PYTHON=/usr/bin/python3.12 ./install.sh`.
Для glibc < 2.28: `PIP_PLATFORMS="manylinux2014_x86_64" PY_VERSION=3.9 make bundle-venv`.

### Параметры install.sh

- `NO_SYSTEMD=1 ./install.sh` — только подготовить, без systemd (покажет команду запуска);
- сервис ставится от системного пользователя `docdiff`, юнит — `/etc/systemd/system/docdiff.service`.

### За nginx / на подпуть

Интерфейс использует относительные пути, поэтому работает и на подпути вида `/docdiff/`.
Пример конфига: [deploy/nginx.conf.example](deploy/nginx.conf.example).
Не забудьте `client_max_body_size` ≥ 2 × `MAX_UPLOAD_MB`.

> Авторизации в сервисе нет. Если доступ нужно ограничить — закройте его на уровне
> nginx (basic auth / SSO / allow-deny по подсетям) или файрвола.

## 3. Настройки

Файл `.env` рядом с `install.sh` (создаётся из `.env.example`). После изменения:
Docker — `docker compose up -d`, systemd — `sudo systemctl restart docdiff`, вручную — перезапустите `./start.sh`.

| Переменная        | По умолчанию | Описание |
|-------------------|--------------|----------|
| `PORT`            | `8080`       | Порт сервиса (для Docker — порт на хосте) |
| `MAX_UPLOAD_MB`   | `50`         | Максимальный размер одного файла |
| `WORKERS`         | `2`          | Процессов uvicorn; ≈ число одновременных тяжёлых сравнений |
| `SOFFICE_TIMEOUT` | `60`         | Таймаут конвертации через LibreOffice, сек |

### Старые форматы (.doc, .rtf, .odt)

Нативно читаются только современные форматы. Для `.doc/.rtf/.odt/.ods/.ppt/.odp` сервис
конвертирует файл через LibreOffice, если он установлен:

- Docker: `WITH_LIBREOFFICE=1 make bundle-docker` (образ станет ~700 МБ);
- портативный / venv: поставьте на сервер пакет `libreoffice` (`soffice` должен быть в `PATH`).

Если LibreOffice нет — пользователь увидит понятную ошибку с просьбой сохранить файл в `.docx`/`.xlsx`.

## 4. CLI и API

### Командная строка

```bash
.venv/bin/python -m app.cli old.docx new.docx                    # различия в терминале
.venv/bin/python -m app.cli old.xlsx new.xlsx --html report.html # + HTML-отчёт
.venv/bin/python -m app.cli a.txt b.txt -i -w --json diff.json   # без учёта регистра/пробелов, JSON
```

Код выхода: `0` — совпадают, `1` — есть различия, `2` — ошибка. Удобно для скриптов и CI.
В Docker: `docker exec docdiff python -m app.cli …` (файлы нужно смонтировать в контейнер).

### HTTP API

Swagger: `http://<сервер>:8080/api/docs`.

```bash
curl -F file_a=@old.docx -F file_b=@new.docx -F ignore_case=true \
     http://server:8080/api/compare
```

| Метод | Путь           | Описание |
|-------|----------------|----------|
| GET   | `/`            | Веб-интерфейс |
| GET   | `/health`      | Проверка живости (`{"status":"ok"}`) |
| GET   | `/api/info`    | Версия, форматы, наличие LibreOffice |
| POST  | `/api/compare` | `file_a`, `file_b`, `ignore_case`, `ignore_whitespace` → JSON с различиями |

Формат ответа (текстовый режим):

```json
{
  "mode": "text",
  "stats": {"equal": 10, "insert": 1, "delete": 0, "replace": 3, "similarity": 0.69},
  "rows": [
    {"op": "replace", "l": 6, "r": 6,
     "a": [["=", "стоимость "], ["-", "1 250 000"], ["=", " рублей"]],
     "b": [["=", "стоимость "], ["+", "1 310 000"], ["=", " рублей"]]}
  ]
}
```

Для таблиц `mode: "table"` и массив `sheets[]`, где у каждой строки `cells: [[статус, было, стало], …]`
(`=` без изменений, `~` изменено, `+`/`-` строка добавлена/удалена).

## 5. Как это работает

```
app/
  parsers.py   — чтение форматов → TextDoc (строки) или TableDoc (листы × строки × ячейки)
  differ.py    — сравнение на difflib (стандартная библиотека Python)
  main.py      — FastAPI: /api/compare, /health, отдача интерфейса
  cli.py       — командная строка и генерация HTML-отчёта
  static/index.html — весь интерфейс в одном файле, без внешних зависимостей
```

1. Документ разбирается на **строки**: абзацы Word, строки таблиц (`| a | b |`), строки PDF по страницам,
   тексты слайдов. Excel/CSV — на **строки листа**.
2. `difflib.SequenceMatcher` выравнивает строки: одинаковые / добавленные / удалённые.
3. В блоках замен строки сопоставляются по похожести (≥ 50 % — «изменена», иначе «удалена + добавлена»).
4. Для изменённых строк считается **пословная** разница, для строк таблиц — **поячеечная**.

Движок сравнения изолирован в `differ.py`: если понадобится заменить `difflib` другой библиотекой,
достаточно поменять его, не трогая парсеры, API и интерфейс.

Ограничения, о которых стоит знать:
- сравнивается **содержимое**, а не оформление (шрифты, цвета, отступы игнорируются);
- в Excel сравниваются **значения** ячеек (для формул — последнее сохранённое значение);
  вставка **столбца** отображается как изменение ячеек правее него (вставка строк распознаётся корректно);
- сканы PDF без текстового слоя не сравниваются (нужен OCR);
- `.doc/.rtf/.odt` — только с LibreOffice.

## 6. Обновление, логи, частые проблемы

**Обновление на сервере:** скачайте новый архив, распакуйте в новый каталог, скопируйте туда старый `.env`
и запустите `sudo ./install.sh` — сервис переключится на новую версию.

### Выпуск новой версии

1. Поднимите версию в `app/__init__.py`.
2. `git commit -am "v1.1.0" && git tag v1.1.0 && git push && git push --tags`
3. GitHub Actions прогонит тесты, соберёт три архива, проверит, что они запускаются,
   и опубликует их в [Releases](https://github.com/daimestrike/DocDiff/releases) вместе с `SHA256SUMS.txt`.

**Логи:**
- Docker: `cd /opt/docdiff && docker compose logs -f`
- systemd: `journalctl -u docdiff -f`

**Проблемы:**

| Симптом | Решение |
|---------|---------|
| `пакет собран под Python 3.11, а на сервере 3.9` | Возьмите портативный архив или `PY_VERSION=3.9 make bundle-venv` |
| `встроенный Python не запустился` | Архив не под ту архитектуру: проверьте `uname -m` (x86_64 / aarch64) |
| `exec format error` в Docker | Образ не под ту архитектуру: `PLATFORM=linux/arm64 make bundle-docker` |
| `413 Файл больше … МБ` | Увеличьте `MAX_UPLOAD_MB` (и `client_max_body_size` в nginx) |
| `Формат .doc поддерживается только при установленном LibreOffice` | См. [Старые форматы](#старые-форматы-doc-rtf-odt) |
| Порт 8080 занят | Поменяйте `PORT` в `.env` |
| Долго сравнивается огромный файл | Увеличьте `WORKERS`; сравнение больших таблиц (100k+ строк) может занимать десятки секунд |
