# О проекте

## Зачем

В работе постоянно приходят «новые версии» документов: договор после правок контрагента, обновлённый прайс поставщика, исправленный регламент, выгрузка из учётной системы. Найти глазами, что изменилось, долго и ненадёжно, а встроенное сравнение Word и Excel есть не у всех, неудобно и не работает между форматами.

**DocDiff** решает одну задачу: показать разницу между двумя версиями документа быстро и наглядно, прямо в браузере, без установки программ на рабочие места.

## Для кого

| Кто | Типичный сценарий |
|---|---|
| Юристы, договорной отдел | Что контрагент поменял в договоре или допсоглашении: суммы, сроки, новые пункты |
| Закупки, категорийные менеджеры | Какие позиции, цены и остатки изменились в прайсе или спецификации поставщика |
| Финансы, аналитики | Сверка двух выгрузок или отчётов в Excel/CSV по ячейкам |
| Методологи, служба качества | Что изменилось в новой редакции регламента или инструкции |
| ИТ, администраторы | Разница конфигов, SQL-скриптов, JSON/YAML; массовое сравнение через CLI и API |

## Как это выглядит для пользователя

1. Открыть DocDiff в браузере.
2. Перетащить старую и новую версию.
3. Сразу увидеть результат: процент совпадения, число добавленных, удалённых и изменённых строк, подсветку до слова (текст) или до ячейки (таблицы).
4. При необходимости скачать HTML-отчёт и отправить коллеге.

Подробно: [Руководство пользователя](04-user-guide.md).

## Ключевые свойства

- **Много форматов**: Word, Excel, CSV, PDF, PowerPoint, текст и код; со старыми `.doc`/`.rtf`/`.odt` — через LibreOffice. Можно сравнивать разные форматы между собой, например `.docx` и `.pdf`.
- **Табличное сравнение для Excel**: строки выравниваются, так что вставка строки не превращает всю таблицу в «изменения».
- **Мгновенно**: сравнение запускается, как только выбран второй файл.
- **Закрытый контур**: работает без интернета, интерфейс не обращается к внешним ресурсам.
- **Конфиденциальность**: документы не хранятся, временные данные удаляются сразу после ответа.
- **Простое развёртывание**: один архив, одна команда `sudo ./install.sh`, Python и библиотеки уже внутри.
- **Интеграции**: CLI с кодами возврата для скриптов, HTTP API с JSON-ответом.

## Чего DocDiff не делает

- Не сравнивает **оформление**: шрифты, цвета, отступы, картинки.
- Не распознаёт **сканы** (OCR нет).
- Не хранит историю сравнений и не ведёт версии документов.
- Не имеет собственной авторизации: доступ ограничивается сетью или nginx ([Настройка](06-configuration.md#ограничение-доступа)).

## Технологии

| Компонент | Что используется |
|---|---|
| Язык | Python 3.11 (в портативной сборке — встроенный) |
| Веб-сервер | FastAPI + uvicorn |
| Сравнение | `difflib` из стандартной библиотеки Python |
| Чтение форматов | python-docx, openpyxl, xlrd, pypdf, python-pptx |
| Интерфейс | Один HTML-файл без фреймворков и внешних зависимостей |
| Поставка | Портативный архив, Docker-образ, пакет под системный Python |
| CI/CD | GitHub Actions: тесты, сборка и проверка архивов, публикация в Releases |

Подробно: [Архитектура](10-architecture.md).

## Требования

| | Минимум |
|---|---|
| ОС сервера | Linux x86_64 или aarch64, glibc ≥ 2.17 (CentOS 7+, Astra, РЕД ОС, Debian, Ubuntu…) |
| Ресурсы | 1 vCPU, 512 МБ RAM; для больших таблиц — больше памяти |
| Диск | ~150 МБ после распаковки |
| Сеть | Интернет не нужен. Пользователям нужен доступ к порту (по умолчанию 8080) |
| Клиент | Любой современный браузер |
