# DocDiff — сравнение документов

**DocDiff** — веб-сервис для внутреннего контура: загружаете две версии документа и сразу видите, что изменилось.

![статус](https://github.com/daimestrike/DocDiff/actions/workflows/ci.yml/badge.svg)

## Возможности

- **Word** — абзацы, заголовки, таблицы; изменения подсвечиваются до слова.
- **Excel / CSV** — сравнение по листам и строкам: добавленные и удалённые строки, изменённые ячейки (`C3: 79 → 84`), новые и удалённые листы.
- **PDF, PowerPoint, текстовые файлы** (UTF-8 и Windows-1251).
- Сравнение запускается **сразу**, как только выбран второй файл.
- **HTML-отчёт** одним файлом — открывается в любом браузере без сервера.
- **CLI и HTTP API** для скриптов и интеграций.
- **Работает без интернета**: Python и библиотеки уже в архиве, интерфейс не грузит внешних ресурсов.
- **Файлы не хранятся**: временные данные удаляются сразу после сравнения.
