# Форматы файлов

| Формат | Расширения | Как сравнивается |
|---|---|---|
| Word | `.docx`, `.docm` | По абзацам и строкам таблиц, внутри — по словам. Заголовки помечаются `#` |
| Excel | `.xlsx`, `.xlsm`, `.xls` | По листам → строкам → ячейкам. Сравниваются **значения** |
| CSV / TSV | `.csv`, `.tsv` | Как таблица. Разделитель (`,` `;` `\t` `\|`) и кодировка определяются автоматически |
| PDF | `.pdf` | По строкам текста, с метками страниц. Нужен текстовый слой |
| PowerPoint | `.pptx` | По слайдам: текст фигур, таблицы, заметки докладчика |
| Текст и код | `.txt .md .json .xml .yaml .yml .html .toml .ini .cfg .conf .env .properties .log .sql .sh .bat .ps1 .py .js .ts .java .go .cs .kt .php .rb` | По строкам, внутри — по словам. UTF-8 или Windows-1251 |
| Старые форматы | `.doc .rtf .odt .ods .ppt .odp` | Только если на сервере есть LibreOffice — см. [Настройка](Настройка#старые-форматы-doc-rtf-odt) |

## Разные форматы между собой

Можно сравнить, например, `.docx` с `.pdf` или `.xlsx` с `.txt` — оба файла приводятся к тексту. Две таблицы (Excel/CSV) всегда сравниваются в табличном режиме.

## Особенности

**Excel**
- Формулы сравниваются по **последнему сохранённому значению**. Если файл создан программно и ни разу не открывался в Excel, значения формул могут быть пустыми.
- Вставка **строк** распознаётся корректно. Вставка **столбца** показывается как изменение ячеек правее него.
- Если в обоих файлах по одному листу, они сравниваются даже при разных названиях. Иначе листы сопоставляются по имени.
- Даты показываются как `2024-03-15`, логические значения — `ИСТИНА`/`ЛОЖЬ`.

**Word**
- Объединённые ячейки таблиц учитываются один раз.
- Колонтитулы, сноски и примечания не сравниваются.
- Режим рецензирования: сравнивается текущий текст документа.

**PDF**
- Качество зависит от того, как PDF создан. Документ, сохранённый из Word, сравнивается хорошо; скан — никак (нужен OCR).
- Перенос строк в PDF может отличаться от оригинала, поэтому при сравнении PDF с Word различий будет больше, чем по факту.

## Ограничения размера

По умолчанию до **50 МБ** на файл. Меняется параметром `MAX_UPLOAD_MB` — см. [Настройка](Настройка).
