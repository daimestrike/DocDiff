# Архитектура

```
Браузер ──HTTP──► FastAPI (app/main.py)
                     │  POST /api/compare
                     ▼
               parsers.py ── файл → TextDoc | TableDoc
                     │
                     ▼
               differ.py  ── difflib → JSON с различиями
                     │
                     ▼
         static/index.html рендерит результат
```

| Файл | Назначение |
|---|---|
| `app/parsers.py` | Чтение форматов, приведение к `TextDoc` (список строк) или `TableDoc` (листы → строки → ячейки) |
| `app/differ.py` | Движок сравнения на `difflib` из стандартной библиотеки Python |
| `app/main.py` | HTTP API (FastAPI), лимит размера, отдача интерфейса |
| `app/cli.py` | Командная строка и генерация HTML-отчёта |
| `app/config.py` | Настройки из переменных окружения |
| `app/static/index.html` | Весь интерфейс в одном файле: HTML + CSS + JS, без внешних зависимостей |

## Алгоритм сравнения

1. **Разбор.** Документ → последовательность строк: абзацы Word, строки таблиц (`| a | b |`), строки PDF по страницам, тексты слайдов. Excel/CSV → строки листа с ячейками.
2. **Выравнивание.** `difflib.SequenceMatcher` находит общие участки и помечает строки как одинаковые, добавленные, удалённые или заменённые.
3. **Сопоставление замен.** Внутри блока замен каждая строка ищет самую похожую строку из другой версии. Похожесть ≥ 50% → «изменена», иначе «удалена + добавлена». Это даёт осмысленный результат, когда между изменёнными строками вставлены новые.
4. **Детализация.** Для изменённой строки текста — разница по словам. Для строки таблицы — по ячейкам.
5. **Нормализация.** Опции «регистр/пробелы» применяются к ключам сравнения, а показывается исходный текст.

Сложность: для типичных документов — доли секунды. Для блоков замен больше 40 000 пар строк попарное сопоставление отключается (строки сопоставляются по порядку), чтобы не зависнуть на огромных файлах.

| fastapi, uvicorn, python-multipart | HTTP-сервер и загрузка файлов |

| pypdf | PDF |

## Как расширить

**Новый формат** — добавьте функцию `parse_xxx(data: bytes) -> TextDoc | TableDoc` в `parsers.py` и ветку в `parse()`.

**Другой движок сравнения** — всё сравнение сосредоточено в `differ.py`. Достаточно сохранить формат результата (см. [CLI и API](CLI-и-API#формат-ответа-текст)), и интерфейс, CLI и API продолжат работать.

## Безопасность

- Файлы не хранятся: загрузки больше 1 МБ FastAPI временно держит во временной папке (`/tmp`, у systemd-сервиса — изолированный `PrivateTmp`, в Docker — tmpfs в памяти), конвертация LibreOffice — тоже во временной папке; всё удаляется сразу после ответа.
- Интерфейс рендерит текст через `textContent`, HTML из документов не исполняется.
- В HTML-отчёт данные встраиваются с экранированием `<`.
- systemd-сервис работает от непривилегированного пользователя с `NoNewPrivileges`, `ProtectSystem=full`.
- Docker-контейнер: непривилегированный пользователь, read-only файловая система.
- Авторизации нет — ограничивайте доступ сетью или nginx ([Настройка](Настройка#ограничение-доступа)).
