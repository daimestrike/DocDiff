# Решение проблем

## Установка

| Симптом | Причина и решение |
|---|---|
| `встроенный Python не запустился` | Архив не под ту архитектуру. `uname -m`: `x86_64` → `linux-x86_64`, `aarch64` → `linux-aarch64` |
| `cannot execute binary file` / `Exec format error` | То же самое |
| `GLIBC_2.17 not found` | Очень старый Linux (до CentOS 7). Используйте Docker-вариант |
| `пакет собран под Python 3.11, а на сервере 3.9` | Возьмите портативный архив или соберите `PY_VERSION=3.9 make bundle-venv` |
| `docker не найден` | Возьмите портативный архив `linux-x86_64` |
| `exec format error` в Docker | Образ под другую архитектуру: `PLATFORM=linux/arm64 make bundle-docker` |
| `сервис не ответил на /health за 30 секунд` | Смотрите логи (ниже). Частая причина — занят порт |
| `Address already in use` | Порт 8080 занят. Поменяйте `PORT` в `.env` |

## Работа сервиса

| Симптом | Причина и решение |
|---|---|
| Страница не открывается с другого компьютера | Файрвол: `sudo firewall-cmd --add-port=8080/tcp --permanent && sudo firewall-cmd --reload` (или `ufw allow 8080`) |
| `Файл больше 50 МБ` | Увеличьте `MAX_UPLOAD_MB` в `.env`. За nginx — ещё и `client_max_body_size` |
| `413 Request Entity Too Large` от nginx | `client_max_body_size` в конфиге nginx |
| `Формат .doc поддерживается только при установленном LibreOffice` | Пересохраните в `.docx` или установите LibreOffice — см. [Настройка](Настройка#старые-форматы-doc-rtf-odt) |
| `Не удалось прочитать «файл»` | Файл повреждён, защищён паролем или расширение не соответствует содержимому |
| PDF: «документы пустые» или странные различия | PDF — скан без текстового слоя, либо сильно отличается вёрстка |
| Excel: пустые значения в ячейках с формулами | Файл сохранён без вычисленных значений. Откройте и сохраните его в Excel |
| Excel: вставил столбец — вся таблица «изменена» | Известное ограничение: вставка столбцов показывается как изменение ячеек |
| Долго сравнивает | Очень большие таблицы. Увеличьте `WORKERS`, если пользователей много |

## Логи

| Установка | Команда |
|---|---|
| systemd | `journalctl -u docdiff -f` |
| Docker | `cd /opt/docdiff && docker compose logs -f` |
| `./start.sh` | вывод в терминале |
