# Быстрый старт

Установка на Linux-сервер **без доступа в интернет** — 3 шага.

## 1. Скачайте архив

На любой машине с интернетом откройте [последний релиз](https://github.com/daimestrike/DocDiff/releases/latest) и скачайте архив из раздела **Assets**.

Какой брать — зависит от сервера. Узнать архитектуру: `uname -m`.

| `uname -m` | Docker на сервере | Архив |
|---|---|---|
| `x86_64` | не нужен | `docdiff-X.Y.Z-linux-x86_64.tar.gz` ← **обычно этот** |
| `aarch64` | не нужен | `docdiff-X.Y.Z-linux-aarch64.tar.gz` |
| `x86_64` | есть | `docdiff-X.Y.Z-docker-amd64.tar.gz` |

> Кнопки «Source code (zip/tar.gz)» — это только исходники. Без интернета они не запустятся.

## 2. Перенесите на сервер

Любым доступным способом: `scp`, общая папка, флешка.

```bash
scp docdiff-1.0.0-linux-x86_64.tar.gz user@server:/opt/
```

Проверить целостность (необязательно): сравните `sha256sum docdiff-*.tar.gz` с файлом `SHA256SUMS.txt` из релиза.

## 3. Установите

```bash
cd /opt
tar xzf docdiff-1.0.0-linux-x86_64.tar.gz
cd docdiff
sudo ./install.sh
```

Скрипт проверит архив, создаст системного пользователя `docdiff`, поставит systemd-сервис с автозапуском и дождётся, пока сервис ответит.

Откройте в браузере: **`http://<адрес-сервера>:8080`**

### Нет root-доступа?

```bash
./start.sh
```

Сервис запустится в текущем терминале. Для фоновой работы — `nohup ./start.sh &` или `screen`/`tmux`.
