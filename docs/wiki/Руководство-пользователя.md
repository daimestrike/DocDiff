# Руководство пользователя

Страница для тех, кто будет сравнивать документы. Ничего устанавливать не нужно — только браузер.

## Как сравнить два документа

1. Откройте DocDiff в браузере (адрес подскажет администратор, например `http://docdiff.local:8080`).
2. Перетащите **старую** версию в левое поле «Документ A · было».
3. Перетащите **новую** версию в правое поле «Документ B · стало».

Сравнение запустится автоматически. Можно перетащить оба файла сразу в любое поле — первый станет «было», второй «стало».

Перепутали местами — нажмите **⇄** между полями.

## Как читать результат

Сверху — сводка:

| Элемент | Значение |
|---|---|
| **87%** | Доля совпадающих строк |
| <span>+3 добавлено</span> | Новые строки, которых не было |
| <span>−1 удалено</span> | Строки, которых больше нет |
| <span>~2 изменено</span> | Строки, в которых поменялась часть текста |

### Текстовые документы (Word, PDF, PowerPoint, текст)

Две колонки: слева «было», справа «стало».

- 🟥 красный фон — строка удалена или изменена (слева);
- 🟩 зелёный фон — строка добавлена или изменена (справа);
- **ярко выделенные слова** — что именно поменялось внутри строки;
- штриховка — на этом месте в другой версии строки нет.

Таблицы из Word показываются строками вида `| Товар | Кол-во | Цена |`.

### Таблицы (Excel, CSV)

Один лист — одна вкладка. Цветная точка на вкладке:

- 🟡 есть изменения · 🟢 лист добавлен · 🔴 лист удалён · ⚪ без изменений

В таблице:

- зелёная строка — добавлена;
- зачёркнутая красная строка — удалена;
- жёлтая ячейка — значение изменилось: сверху старое (зачёркнуто), снизу новое.

Столбец **A / B** — номера строк в старом и новом файле (`— / 5` значит, что строка есть только в новом).

## Удобства

| Что | Как |
|---|---|
| Только различия | Галочка «Только различия» сворачивает одинаковые фрагменты. Клик по «⋯ N одинаковых строк» разворачивает их |
| Переход к изменениям | Кнопки **↑ Пред.** / **↓ След.** или клавиши `p` / `n` |
| Не учитывать регистр | «Договор» и «договор» считаются одинаковыми |
| Не учитывать пробелы | Лишние пробелы и отступы не считаются изменением |
| Сохранить результат | **⤓ Отчёт HTML** — один файл, открывается в любом браузере без сервера. Удобно отправить по почте |

## Что сравнивается, а что нет

✅ Текст, числа, значения ячеек, порядок строк, листы Excel.

❌ Оформление: шрифты, цвета, жирность, отступы, картинки. Сканы PDF без текстового слоя.

Подробнее: [Форматы файлов](Форматы-файлов).

## Конфиденциальность

Файлы не хранятся на сервере и никуда не отправляются: крупные загрузки на время сравнения попадают во временную папку и удаляются сразу после ответа.
