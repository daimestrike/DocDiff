# Настройка

Настройки хранятся в файле `.env` в папке установки (создаётся из `.env.example` при первом запуске).

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `8080` | Порт сервиса. Для Docker — порт на хосте |
| `MAX_UPLOAD_MB` | `50` | Максимальный размер одного файла, МБ |
| `WORKERS` | `2` | Число процессов. ≈ сколько тяжёлых сравнений идёт параллельно |
| `SOFFICE_TIMEOUT` | `60` | Таймаут конвертации через LibreOffice, секунд |
| `HOST` | `0.0.0.0` | Адрес, на котором слушает сервис (кроме Docker) |

После изменения перезапустите:

| Установка | Команда |
|---|---|
| systemd | `sudo systemctl restart docdiff` |
| Docker | `cd /opt/docdiff && docker compose up -d` |
| Вручную | остановить и снова `./start.sh` |

## Размещение за nginx

Интерфейс использует относительные пути, поэтому работает и на подпути (`https://tools.company.local/docdiff/`).

```nginx
location /docdiff/ {
    proxy_pass http://127.0.0.1:8080/;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 110m;   # 2 файла × MAX_UPLOAD_MB + запас
    proxy_read_timeout 300s;
}
```

Шаблон лежит в архиве: `deploy/nginx.conf.example`.

## Ограничение доступа

В DocDiff нет логина и пароля — любой, кто видит порт, может пользоваться сервисом. Если нужно ограничить:

**По подсетям (nginx):**
```nginx
location /docdiff/ {
    allow 10.0.0.0/8;
    deny all;
    ...
}
```

**Basic-авторизация (nginx):**
```bash
htpasswd -c /etc/nginx/docdiff.htpasswd ivanov
```
```nginx
location /docdiff/ {
    auth_basic "DocDiff";
    auth_basic_user_file /etc/nginx/docdiff.htpasswd;
    ...
}
```

**Только через nginx** — чтобы порт 8080 не был доступен напрямую, добавьте `HOST=127.0.0.1` в `.env`. Для Docker — поменяйте в `docker-compose.yml` строку портов на `"127.0.0.1:8080:8080"`.

## Старые форматы (.doc, .rtf, .odt)

Нативно читаются только современные форматы. `.doc .rtf .odt .ods .ppt .odp` сервис конвертирует через LibreOffice, если тот установлен:

- **Портативный / системный Python**: установите на сервер пакет `libreoffice` из локального зеркала — команда `soffice` должна быть в `PATH`. Перезапустите сервис.
- **Docker**: соберите образ с LibreOffice (~700 МБ):
  ```bash
  WITH_LIBREOFFICE=1 make bundle-docker
  ```

Проверить: `curl http://localhost:8080/api/info` → `"libreoffice": true`.

Без LibreOffice пользователь увидит сообщение с просьбой пересохранить файл в `.docx`/`.xlsx`.

## Производительность

- Обычные документы (до сотен страниц / десятков тысяч строк) сравниваются за доли секунды.
- Таблицы на 100 000+ строк могут обрабатываться десятки секунд. Увеличьте `WORKERS`, если с сервисом работает много людей.
- Большие таблицы занимают заметно больше памяти, чем размер файла: при сравнении файлов в десятки МБ следите за RAM сервера.
